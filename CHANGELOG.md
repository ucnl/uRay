## [0.5.0] — 2026-09-22

### Добавлено
- Достижения уровней с прогрессом в localStorage
- Модальное окно со списком достижений
- Вводные сообщения уровней (`message`)
- Футер со ссылками и версией
- PWA: манифест, Service Worker, иконки
- Синхронизация звука с TOF
- Новые уровни: `multipath`, `long_shallow`, `resonator`, `trap`, `zigzag`

### Изменено
- Единый порог `eMin` для трассировки и попадания
- Режимы `Impulse` и `Ping` для звука
- Сектор направленности рисуется в экранных пикселях
- Достижения откалиброваны по уровням

### Удалено
- Режим звука `Hybrid` (не использовался)
- Кнопка скорости `∞` (дублировала Explore)

## [0.4.0] — 2026-09-21

### Добавлено
- Режимы Explore / Game
- Анимация проявления луча с fade
- Импульсная характеристика (ИХ) с маркером
- Звук через WebAudio: пинги по лучам
- Мобильная раскладка

## [0.3.0] — 2026-09-21

### Добавлено
- Drag-управление, колесо мыши, стрелки, Space
- 13 уровней с разными явлениями
- Режим Game с скрытыми лучами
- Publish на GitHub Pages

## [0.1.0] — 2026-09-20

### Добавлено
- Физика: RK4 по длине дуги, рефракция, отражения
- Ломаная дна
- Веер лучей с гауссовой ДН
- Canvas-рендер: сцена и профиль c(z)
